# وب‌سایت شخصی دانیال مرادی

وب‌سایت معرفی شخصی، برند شخصی و نمونه‌کار با طراحی مدرن (Glassmorphism + Dark Mode)، ساخته‌شده با **HTML5, CSS3, JavaScript خالص** به‌علاوه‌ی **GSAP/ScrollTrigger** برای انیمیشن‌های اسکرول (طبق درخواست صریح در بریف).

## ساختار پروژه

```
├── index.html          صفحه اصلی (تمام بخش‌ها: Home, About, Skills, Services, Portfolio, Contact)
├── search.html           موتور جستجوی داخلی — جستجو بین سایت‌های ساخته‌شده توسط دانیال کد
├── search-data.js        ایندکس (لیست) سایت‌ها برای موتور جستجو — همینجا سایت جدید اضافه کن
├── search-engine.js      منطق جستجو و نمایش نتایج (نیازی به تغییر نیست)
├── style.css            استایل کامل سایت (Design Tokens, Components, Responsive, A11y)
├── script.js             تمام رفتارهای تعاملی (Loader, Cursor, Parallax, Counters, Form...)
├── robots.txt            دستورات ایندکس برای موتورهای جست‌وجو
├── sitemap.xml           نقشه سایت برای سئو
├── manifest.json         مانیفست PWA
└── assets/
    ├── images/            تصاویر نمونه‌کار و OG (SVG placeholder)
    ├── icons/             آیکون/فاویکون (favicon.svg)
    └── fonts/             (خالی — فونت‌ها از Google Fonts CDN با preconnect/preload بارگذاری می‌شوند)
```

## قبل از انتشار — موارد ضروری برای شخصی‌سازی

این پروژه با **محتوای واقعی و متن نهایی** آماده شده، اما چند مورد placeholder باقی مانده که باید با اطلاعات واقعی جایگزین شود:

1. **دامنه:** دامنه همه‌جا `https://danyalcode.ir/` است (در `<head>`، schema.org، `sitemap.xml`، `robots.txt`). اگر دامنه‌ی نهایی فرق دارد، همین آدرس را جایگزین کنید.
2. **شماره تلفن:** مقدار `+98 912 000 0000` در بخش تماس یک Placeholder است.
3. **ایمیل، لینک شبکه‌های اجتماعی (`href="#"`)** در بخش Contact را با آدرس‌های واقعی گیت‌هاب/لینکدین/اینستاگرام/تلگرام جایگزین کنید.
4. **تصاویر نمونه‌کار:** فایل‌های `assets/images/project-0X.svg` و `og-cover.svg` تصاویر Placeholder گرادیانی هستند. برای بهترین نتیجه در سئو و شبکه‌های اجتماعی:
   - تصاویر واقعی پروژه‌ها را در فرمت **WebP** (با فallback JPEG) جایگزین کنید.
   - `og-cover.svg` را به یک تصویر PNG/JPG با ابعاد ۱۲۰۰×۶۳۰ تبدیل کنید، چون فیسبوک/توییتر از SVG برای og:image پشتیبانی کامل نمی‌کنند.
5. **فاویکون:** یک نسخه PNG (مثلاً ۱۹۲×۱۹۲ و ۵۱۲×۵۱۲) از `favicon.svg` نیز برای سازگاری کامل با همه مرورگرها و اپل تولید و در `manifest.json` اضافه کنید.
6. **فرم تماس:** ارسال فرم در حال حاضر به‌صورت شبیه‌سازی‌شده (client-side) است. برای عملکرد واقعی، آن را به یک سرویس بک‌اند یا فرم‌هندلر (مثل Formspree, EmailJS یا API اختصاصی) متصل کنید.

## موتور جستجوی داخلی (صفحه جستجو)

صفحه `search.html` یک موتور جستجوی کوچک و اختصاصی است که فقط بین سایت‌هایی می‌گردد که خودت (دانیال کد) ساخته‌ای — دقیقاً مثل نحوه کار ایندکس گوگل، ولی محدود به کارهای خودت.

- **برای اضافه کردن یک سایت جدید به نتایج جستجو**، فقط فایل `search-data.js` را باز کن و یک آبجکت جدید با `title` (عنوان)، `url` (آدرس کامل سایت) و `description` (توضیح کوتاه) به آرایه `SITE_INDEX` اضافه کن. یک نمونه آماده و کامنت‌گذاری‌شده داخل همان فایل هست که می‌توانی کپی کنی.
- نیازی به تغییر `search.html` یا `search-engine.js` نیست؛ صفحه جستجو به‌صورت خودکار از روی `search-data.js` نتایج را می‌سازد.
- اگر کاربر عبارتی را جستجو کند که با هیچ‌کدام از سایت‌های ثبت‌شده مطابقت نداشته باشد، پیام «متأسفانه دانیال کد هنوز چنین سایتی نساخته، ولی قراره بسازه» به‌صورت خودکار نمایش داده می‌شود.
- جستجو کاملاً سمت کاربر (client-side) و بدون نیاز به سرور یا دیتابیس کار می‌کند.

## عملکرد و سئو

- Semantic HTML5، ARIA labels، alt متن برای تمام تصاویر، `loading="lazy"` روی تصاویر نمونه‌کار.
- Schema.org (`Person`, `WebSite`, `BreadcrumbList`)، Open Graph، Twitter Card، لینک Canonical.
- `preconnect`/`dns-prefetch` برای فونت‌ها و CDN، فونت با `font-display: swap`.
- انیمیشن‌ها `prefers-reduced-motion` را رعایت می‌کنند و در نبود GSAP (مثلاً قطعی شبکه) به‌صورت fallback محتوا بدون افکت نمایش داده می‌شود.
- برای نمره کامل Lighthouse، پیش از انتشار:
  - CSS/JS را Minify کنید (مثلاً با ابزارهایی مانند `esbuild`, `cssnano`, یا build step مشابه).
  - تصاویر واقعی را به WebP فشرده تبدیل کنید.
  - در صورت میزبانی روی سرور خودتان، فایل‌های فونت را به‌صورت self-hosted سرو و preload کنید تا کاملاً مستقل از CDN باشید.

## اجرای محلی

فایل `index.html` را مستقیم در مرورگر باز کنید یا با یک سرور استاتیک سرو کنید:

```bash
npx serve .
```

## یادداشت فنی

طبق بریف، پیاده‌سازی اصلی صرفاً با HTML/CSS/JS خام انجام شده؛ تنها استثنا، کتابخانه‌ی **GSAP + ScrollTrigger** است که به‌صراحت در بخش «انیمیشن» بریف درخواست شده بود و از طریق CDN بارگذاری می‌شود. اگر تمایل دارید سایت کاملاً بدون هیچ کتابخانه خارجی باشد، تابع `initScrollReveal`/`runEntranceAnimation` در `script.js` را با پیاده‌سازی معادل مبتنی بر `IntersectionObserver` جایگزین کنید (fallback ساده‌ای از این منطق از قبل در کد وجود دارد).

## تجربه‌ی سه‌بعدی (3d.js)

فایل `3d.js` یک دنیای Three.js (r128، از cdnjs) با تم **کد و VS Code** پشت همه‌ی صفحه‌ها می‌گذارد:

- **اول صفحه‌ی اصلی:** عکس `assets/images/hero-bg.webp` داخل یک پنجره‌ی سه‌بعدی شبیه VS Code است که با ماوس کج می‌شود؛ جلوی آن کارت‌های کد و علامت‌های سه‌بعدی `</>` و `{ }` در عمق‌های مختلف شناورند.
- **با اسکرول:** دوربین از میان پنجره‌های کد (JS، Python، HTML، CSS، ترمینال)، علامت‌های سه‌بعدی، مکعب‌های کد و بارانِ کد حرکت می‌کند و آخر به مکعب `</>` کنار فوتر می‌رسد.
- کارت‌های شیشه‌ای با ماوس به‌صورت سه‌بعدی کج می‌شوند.

نکته‌ها:

- متن کدها در تابع‌های `SNIPS` و `GLYPHS` بالای فایل قابل تغییر است.
- برای خاموش کردن در همه‌ی سایت: دو تگ `<script>` مربوط به `three.min.js` و `3d.js` را از صفحه‌ها حذف کنید.
- عکس از طریق WebGL بارگذاری می‌شود، پس سایت باید روی سرور (مثل GitHub Pages) باشد؛ با باز کردن مستقیم فایل (`file://`) همان عکس قبلی CSS نمایش داده می‌شود.
- صفحه‌های `blog-*`، `learn-*`، `search` و `results` عمداً ملایم‌تر هستند.
- «کاهش حرکت» سیستم‌عامل و دستگاه‌های لمسی رعایت می‌شود.

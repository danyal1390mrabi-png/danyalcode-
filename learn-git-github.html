آموزش گیت و گیت‌هاب؛ ذخیره‌ی هوشمند پروژه

دانیال مرادی·۹ مهر ۱۴۰۵·6 دقیقه مطالعه

گیت یک سیستم کنترل نسخه است: هر تغییر مهم را «ثبت» می‌کنید و هر زمان خواستید به نسخه‌ی قبل برمی‌گردید. گیت‌هاب هم جایی است که این پروژه‌ها را آنلاین نگه می‌دارید و به اشتراک می‌گذارید.

۱. شروع

git init
git add .
git commit -m "نسخه اول پروژه"

۲. دستورات روزمره

  • git status — دیدن وضعیت فایل‌ها
  • git log --oneline — تاریخچه‌ی کامیت‌ها
  • git diff — دیدن تغییرات هنوز ثبت‌نشده

۳. شاخه (Branch)

برای امتحان یک ویژگی جدید بدون خراب کردن نسخه‌ی اصلی، شاخه بسازید:

git switch -c feature-contact-form
# ... تغییرات ...
git switch main
git merge feature-contact-form

۴. اتصال به گیت‌هاب

git remote add origin https://github.com/USERNAME/my-project.git
git push -u origin main

۵. انتشار رایگان با GitHub Pages

برای سایت‌های استاتیک (فقط HTML/CSS/JS)، در تنظیمات مخزن بخش Pages را روشن کنید تا سایت شما روی یک آدرس عمومی منتشر شود.

نکته امنیتی: هرگز رمز عبور، کلید API یا اطلاعات خصوصی را داخل مخزن عمومی قرار ندهید؛ حتی اگر بعداً حذفشان کنید، در تاریخچه می‌مانند.

قدم بعد: وقتی سایتتان منتشر شد، مبانی سئو کمک می‌کند در گوگل دیده شود.

گیت و گیت‌هاب چه فرقی دارند؟

گیت ابزار کنترل نسخه روی سیستم شماست و گیت‌هاب سرویسی آنلاین برای نگه‌داری و اشتراک‌گذاری پروژه‌های گیت. گیت را بدون گیت‌هاب هم می‌توان استفاده کرد.

کنترل نسخه به چه دردی می‌خورد؟

هر تغییر مهم را ثبت می‌کنید و اگر چیزی خراب شد به نسخه‌ی قبلی برمی‌گردید؛ کار گروهی روی یک پروژه هم ساده‌تر می‌شود.

چطور سایتم را رایگان منتشر کنم؟

برای سایت‌های ایستا می‌توان از GitHub Pages استفاده کرد؛ پروژه را به یک مخزن در گیت‌هاب بفرستید و انتشار را از تنظیمات مخزن فعال کنید.

آموزش جاوااسکریپت از صفر؛ مفاهیم اصلی

دانیال مرادی·۹ مهر ۱۴۰۵·8 دقیقه مطالعه

جاوااسکریپت زبانی است که به صفحه‌ی وب «رفتار» می‌دهد: کلیک، فرم، انیمیشن و ارتباط با سرور. خوشبختانه برای شروع، فقط به یک مرورگر نیاز دارید.

۱. متغیرها و انواع داده

const name = "دانیال";   // مقدار ثابت
let score = 10;          // مقدار قابل تغییر
score = score + 5;
const skills = ["HTML", "CSS", "JS"];
const user = { name: name, age: 20 };

قاعده‌ی ساده: پیش‌فرض از const استفاده کنید و فقط وقتی مقدار تغییر می‌کند، let.

۲. تابع

function greet(name) {
  return "سلام " + name;
}
const double = (n) => n * 2;
console.log(greet("علی"), double(4));

۳. شرط و حلقه

for (const s of skills) {
  if (s === "JS") console.log("این همونیه که الان یاد می‌گیری!");
}

۴. کار با DOM

DOM همان نمایش صفحه‌ی HTML در جاوااسکریپت است. با آن می‌توانید عناصر را پیدا و تغییر دهید:

<button id="btn">کلیک کن</button>
<p id="out"></p>

<script>
  let count = 0;
  document.getElementById("btn").addEventListener("click", () => {
    count++;
    document.getElementById("out").textContent = "تعداد کلیک: " + count;
  });
</script>

۵. دریافت داده از اینترنت

async function load() {
  const res = await fetch("https://example.com/api/data");
  const data = await res.json();
  console.log(data);
}

همیشه خطاها را با try/catch مدیریت کنید؛ شبکه ممکن است قطع باشد.

تمرین: یک لیست کارهای روزانه (To-Do) بسازید که با فشردن دکمه، آیتم جدید اضافه کند و با کلیک روی آیتم، آن را خط بزند.

قدم بعد: اگر دوست دارید سراغ زبانی بروید که برای داده و هوش مصنوعی هم کاربرد دارد، پایتون را ببینید.

پرسش‌های متداول درباره آموزش جاوااسکریپت

آیا قبل از جاوااسکریپت باید HTML بدانم؟

برای برنامه‌نویسی وب بله؛ ابتدا آموزش HTML و CSS را ببینید تا بتوانید با DOM کار کنید. خود زبان را در کنسول مرورگر هم می‌توان تمرین کرد.

تفاوت const و let چیست؟

const برای مقداری است که دوباره مقداردهی نمی‌شود و let برای مقداری که تغییر می‌کند. بهتر است از const شروع کنید و فقط در صورت نیاز let بگذارید.

DOM چیست؟

نمایش درختی صفحه در مرورگر؛ با جاوااسکریپت می‌توانید عنصرها را انتخاب، تغییر یا اضافه کنید و به کلیک و ورودی کاربر واکنش نشان دهید.

آموزش پایتون برای مبتدی‌ها

دانیال مرادی·۹ مهر ۱۴۰۵·7 دقیقه مطالعه

پایتون به‌خاطر خوانایی بالا، یکی از بهترین انتخاب‌ها برای اولین زبان برنامه‌نویسی است و در اتوماسیون، تحلیل داده و هوش مصنوعی هم زیاد استفاده می‌شود. فقط باید پایتون را از سایت رسمی نصب کنید.

۱. اولین برنامه

name = input("اسمت چیه؟ ")
print("سلام", name)

۲. شرط و حلقه

age = 17
if age >= 18:
    print("بزرگسال")
else:
    print("زیر ۱۸ سال")

for i in range(1, 6):
    print(i * i)

در پایتون، تورفتگی (indentation) بخشی از دستور زبان است؛ بلوک‌ها با فاصله‌ی ابتدای خط مشخص می‌شوند.

۳. لیست و دیکشنری

fruits = ["سیب", "موز", "انار"]
fruits.append("گیلاس")

person = {"name": "سارا", "age": 25}
print(person["name"])

۴. تابع

def average(numbers):
    return sum(numbers) / len(numbers)

print(average([12, 15, 18]))

۵. خواندن فایل

with open("notes.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
تمرین: بازی «حدس عدد» بنویسید: برنامه عددی بین ۱ تا ۱۰۰ انتخاب کند (با random.randint) و تا زمانی که کاربر درست حدس نزده، راهنمایی کند.

قدم بعد: کدهایتان را با گیت و گیت‌هاب مدیریت و ذخیره کنید.

بله؛ دستور زبان ساده و خوانایی بالا دارد و در اتوماسیون، تحلیل داده و هوش مصنوعی هم کاربرد دارد.

پایتون را از کجا نصب کنم؟

از سایت رسمی پایتون نسخه‌ی پایدار را دانلود و نصب کنید؛ هنگام نصب در ویندوز گزینه‌ی افزودن پایتون به PATH را فعال کنید.

چرا تورفتگی در پایتون مهم است؟

در پایتون بلوک‌های کد با تورفتگی مشخص می‌شوند، نه با آکولاد؛ تورفتگی اشتباه باعث خطا یا رفتار دیگری می‌شود.
